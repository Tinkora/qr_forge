# 产品范围

[English](./PRODUCT_SCOPE.md)

## 产品定义

qr_forge 是一个聚焦隐私的浏览器工具，用于生成常用二维码以及零售或物流条形码。它服务于需要下载代码图像、但不希望把凭据、联系人或内部网址发送给生成服务的用户。

## 用户与任务

| 用户 | 需要完成的任务 |
| ------ | ---------------- |
| 开发者或运维人员 | 把网址、文本值、电话号码或邮件地址转换为可下载的二维码 |
| IT 支持人员 | 分享 Wi-Fi 连接信息，无须重复输入密码 |
| 个人或小型团队 | 为联系人或活动创建 vCard 二维码 |
| 设计师或内容发布者 | 生成可控制颜色的 SVG 或 PNG，并可选择添加 PNG Logo |
| 零售或物流用户 | 为受支持的 payload 生成符合标准的 Code 128 或 EAN-13 图像 |

隐私需求是真实存在的：用户不应仅为生成图像，就把 Wi-Fi 密码、联系人信息或私密网址发送给无关的二维码 API。

## 0.1 版本范围

### 浏览器应用

- 纯静态应用，没有项目后端、账号、analytics 或 payload 存储
- 默认英文，可切换为简体中文
- 支持网址或文本、Wi-Fi、vCard 3.0、电话、邮件和条形码模式
- 生成后实时预览，并直接下载 SVG 或 PNG
- 可使用键盘操作模式 tab 和表单控件

### 二维码

- 接受底层二维码编码器能够处理的任意非空文本
- 支持 L、M、Q、H 四种纠错级别
- 可配置模块尺寸、静区、前景色和背景色
- 为 WPA 或 WPA2、WEP 和开放网络转义 Wi-Fi payload
- 生成包含姓名、电话、邮件和组织字段的 vCard 3.0 payload
- 可在本地为 PNG 输出叠加 PNG Logo

### 条形码

- Code 128 对可打印 ASCII 使用子集 B，对偶数长度纯数字输入使用子集 C
- 从 12 位输入数字生成 EAN-13，并自动生成校验位
- 包含标准静区，可配置模块宽度和高度，支持 SVG 或 PNG 输出

### 开发者接口

- 用于生成、校验和渲染的 Rust 核心 crate
- 由内置浏览器应用调用的 `wasm-bindgen` 函数
- 由 `CoreError` 表示的机器可读错误码

准确限制和输出行为以[产品契约](./CONTRACT.zh-CN.md)为准。

## 明确的非目标

0.1 版本不提供：

- 托管生成 API、服务端处理、账号或云存储
- MCP server、Agent Skill、ChatGPT action、Codex 集成或其他智能体专用协议
- 受支持的命令行应用
- Data Matrix、UPC、PDF417、Aztec 或其他条形码格式
- 批量生成、CSV 导入、模板、历史记录或已保存项目
- PDF、EPS 或印刷排版输出
- 动态、可过期、可追踪、重定向或动画二维码
- 自动 Logo 安全保证或通用扫描器认证
- npm package、crates.io release 或稳定的 1.0 后 API 承诺
- 原生移动端或桌面应用

这些限制可以避免维护成本和产品声明超出已经实现并验证的行为。

## 隐私边界

应用不会主动传输用户输入的 payload。所有生成和 Logo 解码都在浏览器中完成。静态托管仍会向托管方暴露普通资源请求元数据，浏览器扩展或被修改的部署也可能观察页面内容。下载的输出包含已编码数据。

## 范围变更门禁

建议功能只有满足以下条件，才应进入产品范围：

1. 存在真实用户问题和具体示例，且当前接口无法充分解决
2. 实现范围有界，并有维护负责人
3. 已完成隐私与安全分析
4. 有面向结果的自动化测试，以及现实的浏览器或扫描器验证计划
5. 同步更新英文和简体中文文档
6. 明确判断它是否改变公开契约

实现之前应先创建 GitHub Discussion。规划文档和 issue 必须把未实现工作标记为 proposed，不能将其描述为产品能力。
